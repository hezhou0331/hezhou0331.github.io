# Homepage agent instructions

Read and follow [AGENT.md](AGENT.md) before editing this repository. It contains
the owner's design, content, backup, bilingual, accessibility, and verification
requirements. Keep that file up to date when an approved development convention
changes; this standard `AGENTS.md` is the entry point for coding agents.

For this design pass, work only in the five homepage source files and these
instruction files. Store backups, screenshots, and review notes in the parent
workspace's `tmp/` directory. Preserve pre-existing edits and image files.
Do not commit, push, or deploy unless the owner explicitly requests it.
